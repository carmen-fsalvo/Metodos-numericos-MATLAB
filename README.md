# Metodos-numericos-MATLAB

Este repositorio reúne las herramientas, scripts y funciones desarrolladas en MATLAB durante el Grado en Física de la Universidad Autónoma de Madrid (UAM) para el análisis cuantitativo y resolución de problemas numéricos.

## Contenido del repositorio
* Laboratorio Experimental: Adquisición de datos, tratamiento estadístico de incertidumbres y ajuste de curvas no lineales en experimentos de óptica y electrónica.
* Resolución de Ecuaciones Diferenciales: Integración numérica de sistemas dinámicos (caos, péndulo real y trayectorias).

## Herramientas utilizadas
* MATLAB R202X
* Toolboxes de ajuste de datos (*Curve Fitting*) y procesamiento de señales/gráficos
